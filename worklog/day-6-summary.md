# 6일차 - 취소 가능한 AI 요청 만들기

- 느린 AI 요청을 사용자가 중간에 취소할 수 있는 흐름을 만들었다.
- `plannerAgent`의 draft 요청이 `AbortSignal`을 받을 수 있게 변경했다.
- 생성 중에는 `생성` 버튼 대신 `취소` 버튼이 보이도록 했다.
- 새 요청이 시작되면 이전 요청을 `AbortController`로 무효화했다.
- 취소된 요청의 응답은 preview 상태로 승격되지 않도록 막았다.
- 재생성 중 취소해도 마지막 유효 preview 초안이 복원되도록 했다.
- 취소 후 사용자가 다시 생성할 수 있게 상태를 정리했다.
- `npm run build`로 TypeScript/Vite 빌드를 검증했다.
- 브라우저에서 생성 취소, 정상 생성, 재생성 취소 흐름을 확인했다.
- AI native UI에서는 취소와 마지막 유효 상태 보존이 신뢰감을 만든다는 점을 배웠다.
