# 40일차 - 정책 계약 예제

- Policy Contract Examples는 정책 출력 계약을 대표 사례로 설명하는 설계다.
- 타입은 구조를 고정하고 예제는 그 구조의 실제 의미를 보여준다는 점을 배웠다.
- `RecoverySourceSummaryContractExample` 타입을 추가했다.
- recovery source summary 정책 모듈에 contract examples를 추가했다.
- complete source issue summary 예제를 추가했다.
- truncated source issue summary 예제를 추가했다.
- 각 예제가 input과 expected output을 함께 갖도록 했다.
- State Machine 패널에서 policy examples 개수를 확인할 수 있게 했다.
- 표시 정책이 타입, 정책 snapshot, 계약 예제로 함께 설명되도록 만들었다.
- `npm run build`, diff check, 민감정보 패턴 검색으로 변경을 검증했다.
